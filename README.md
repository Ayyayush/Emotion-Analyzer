# 🧠 Emotion Analyzer

Emotion Analyzer is a **Python-based desktop application** that analyzes text emotions using **Groq LLM APIs**.  
It provides a clean **GUI built with Tkinter** and supports:

- Sentiment (Emotion) Analysis  
- Named Entity Recognition (NER)  
- Language Detection  

The project demonstrates **real-world NLP integration**, clean architecture, and is **deployable as a Windows `.exe`**.

---

## 🚀 Features

- 🔐 User Authentication (Register & Login)
- 💬 Emotion (Sentiment) Analysis  
  - Positive / Neutral / Negative
- 🏷️ Named Entity Recognition  
  - Person, Organization, Location
- 🌍 Language Detection
- 🖥️ Desktop GUI using Tkinter
- ⚡ Powered by Groq LLMs
- 📦 Can be converted into a standalone `.exe`

---

## 🛠️ Tech Stack

- **Python 3.10+**
- **Tkinter** – GUI
- **Groq API** – NLP Processing
- **python-dotenv** – Environment variables
- **JSON** – Local database storage
